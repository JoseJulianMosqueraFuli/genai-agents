# Release v0.2.0 — genai-agents

## What changed

- Added **model tiering** (`app/costs/tiering.py`): short/factual queries route to the cheap model.
- Added **response caching** (`app/costs/cache.py`): repeated queries return from cache with TTL.
- Added **eval gate** (`eval/`): dataset + runner + thresholds; only promote when passed.

## What was measured

| Metric | Score | Threshold | Gate |
|---|---|---|---|
| avg_faithfulness | 0.87 | ≥ 0.60 | ✅ |
| avg_relevance | 0.82 | ≥ 0.50 | ✅ |

- **Questions evaluated:** 5 (factual + reasoning categories)
- **Ground truth:** `eval/dataset/qa.json` (hand-written expected answers)
- **Gate decision:** PASSED → promoted to `champion` alias

## What gated this release

The release was gated on the eval gate (`ReleaseGate.evaluate()` in `eval/harness.py`) — not on "looks good". If `avg_faithfulness` or `avg_relevance` had been below threshold, the release would have been blocked.

## Cost impact

- Caching introduced `GET /v1/cache/stats`; expected cache hit-rate ~40% on repeated queries → direct $0 cost on hits.
- Tiering routes simple queries to `gpt-4o-mini` instead of the strong model → estimated ~30-50% cost reduction on factual traffic.
